HTTP REST + MCP

API Reference

Complete reference for all HTTP REST API endpoints and MCP tools.

Base URL: http://localhost:63987MCP: http://localhost:63988

# HTTP REST API

POST/api/tasksSubmit Task

Submit a new code-generation task to the queue.

Request Body 

{
  "projectPath": "/path/to/project",
  "targetFile": "output.go",
  "instruction": "Write a function that sorts strings",
  "contextFiles": ["main.go", "utils.go"],
  "modelId": "codellama",
  "providerHint": "LM Studio",
  "command": "execute"
}

Fields

FieldRequiredDescription
projectPathYesAbsolute path to the project directory
targetFileYesRelative path for the generated output file
instructionYesNatural language prompt for the LLM
contextFilesNoList of files to include as context
modelIdNoConstrain to a specific model
providerHintNoPrefer a specific provider by name
commandNoTask type: plan, execute, or auto (default: auto)

Response 201 Created

{
  "id": "a1b2c3d4-e5f6-...",
  "projectPath": "/path/to/project",
  "targetFile": "output.go",
  "instruction": "Write a function that sorts strings",
  "status": "QUEUED",
  "command": "execute",
  "createdAt": "2025-01-01T00:00:00Z",
  "updatedAt": "2025-01-01T00:00:00Z"
}
GET/api/tasksList Tasks

Returns all pending (QUEUED or PROCESSING) tasks.

Response 200 OK

[
  {
    "id": "...",
    "status": "QUEUED",
    "instruction": "..."
  }
]
GET/api/tasks/allList All Tasks

List every task including drafts and cancelled (QUEUED, PROCESSING, DRAFT, BACKLOG, COMPLETED, FAILED, CANCELLED).

GET/api/tasks/{id}Get Task

Retrieve a single task by ID.

Response 200 OK

{
  "id": "a1b2c3d4-...",
  "status": "COMPLETED",
  "logs": "generated code output..."
}
DELETE/api/tasks/{id}Cancel Task

Cancel a queued task before it is processed. Returns 204 No Content on success, 404 Not Found if task doesn't exist or already processed.

PUT/api/tasks/{id}Update Task

Update task title, description, or priority.

Request Body 

{
  "instruction": "Updated instruction text",
  "priority": 1
}

Fields

FieldRequiredDescription
instructionNoUpdated instruction
priorityNoPriority: 1=high, 2=medium, 3=low
providerNameNoUpdated provider name
modelIdNoUpdated model ID
tagsNoUpdated tags array
POST/api/tasks/{id}/promotePromote Task

Promote a backlog draft task into the active execution queue.

POST/api/tasks/{id}/claimClaim Task

Claim a QUEUED task for execution by an AI session, transitioning it to PROCESSING.

Request Body 

{
  "sessionId": "session-uuid"
}

Fields

FieldRequiredDescription
sessionIdYesID of the AI session claiming the task
PUT/api/tasks/{id}/statusUpdate Task Status

Report task completion or failure from the executing AI session. Only the session that claimed the task may update it.

Request Body 

{
  "status": "completed",
  "result": "Task output...",
  "sessionId": "session-uuid"
}

Fields

FieldRequiredDescription
statusYesNew status: in_progress | completed | failed
resultNoOutput or log message
sessionIdYesID of the AI session that claimed the task
POST/api/tasks/draftCreate Draft

Create a backlog draft idea for a project without entering the execution queue.

Request Body 

{
  "projectPath": "/path/to/project",
  "instruction": "What the task should do",
  "priority": 2
}

Fields

FieldRequiredDescription
projectPathYesAbsolute path to the project
instructionYesWhat the task should do
targetFileNoFile to write output to
providerNameNoPreferred provider name
modelIdNoPreferred model ID
priorityNoPriority 1=high, 2=medium, 3=low (default 2)
tagsNoLabels array
GET/api/tasks/backlogList Backlog

List all backlog drafts for a project, ordered by priority.

POST/api/brain/ingestIngest Knowledge

Parse and ingest a markdown file (e.g. CLAUDE.md) into the project knowledge repository.

Request Body 

{
  "projectPath": "/your/project",
  "filePath": "/your/project/CLAUDE.md"
}

Fields

FieldRequiredDescription
projectPathYesAbsolute path to the project root
filePathYesPath to the markdown file to ingest

Response 200 OK

{"ingested": 12, "projectPath": "/your/project"}
GET/api/brain/statusBrain Status

Get the knowledge repository status for a project (entry count, last ingested, etc.).

Response 200 OK

{"projectPath": "/your/project", "entryCount": 42, "lastIngested": "2025-01-01T00:00:00Z"}
POST/api/brain/contextGet Project Context

Get macro context for a project (Architectures, Conventions, File Maps) bounded by a token budget.

Request Body 

{
  "projectPath": "/your/project",
  "maxTokens": 800
}

Fields

FieldRequiredDescription
projectPathYesAbsolute path to the project root
maxTokensNoMaximum tokens to return (default: 400)
POST/api/brain/focused-contextGet Focused Context

Get task-specific micro context (Learning, Definitions, Gotchas) based on a semantic query.

Request Body 

{
  "projectPath": "/your/project",
  "question": "How does authentication work?",
  "maxTokens": 400
}

Fields

FieldRequiredDescription
projectPathYesAbsolute path to the project root
questionYesSemantic search query to match against knowledge
maxTokensNoMaximum tokens to return (default: 400)
GET/api/brain/searchSearch Knowledge

Full-text search across the project's knowledge base.

POST/api/brain/initBrain Init

Auto-ingest CLAUDE.md and initialize a project's knowledge base in one step.

Request Body 

{
  "projectPath": "/your/project"
}

Fields

FieldRequiredDescription
projectPathYesAbsolute path to the project root
GET/api/brain/knowledgeList Knowledge

List all knowledge entries for a project, optionally filtered by kind.

DELETE/api/brain/knowledge/{id}Delete Knowledge Entry

Delete a knowledge entry by ID.

GET/api/brain/file-mapGet File Map

Get file path map for a project.

GET/api/providersList Providers

Returns all registered LLM providers with their liveness status.

Response 200 OK

[
  {
    "name": "LM Studio",
    "active": true,
    "activeModel": "codellama",
    "models": ["codellama", "deepseek-coder"]
  },
  {
    "name": "Ollama",
    "active": false
  }
]
POST/api/providersRegister Provider

Dynamically register a new cloud LLM provider.

Request Body 

{
  "name": "My OpenAI",
  "kind": "openai-compat",
  "baseURL": "https://api.openai.com/v1",
  "apiKey": "sk-...",
  "model": "gpt-4o-mini"
}

Fields

FieldRequiredDescription
nameYesDisplay name for the provider
kindYesProvider type: lmstudio, ollama, openai-compat, anthropic
baseURLYesAPI endpoint URL
apiKeyNoRequired for cloud providers
modelNoDefault model to use
DELETE/api/providers/{name}Remove Provider

Deregister a provider by name.

GET/api/providers/configList Provider Configs

List all persisted LLM provider configuration records.

POST/api/providers/configAdd Provider Config

Persist a provider configuration with API-key masking.

Request Body 

{
  "kind": "anthropic",
  "name": "My Claude",
  "base_url": "https://api.anthropic.com/v1",
  "api_key": "sk-ant-...",
  "enabled": true
}

Fields

FieldRequiredDescription
kindYesProvider kind: lmstudio, ollama, openai, anthropic
nameYesDisplay name for the provider
base_urlNoAPI base URL
api_keyNoAPI key if required
enabledNoWhether to activate the provider immediately
PUT/api/providers/config/{id}Update Provider Config

Update an existing persisted provider configuration by ID.

Fields

FieldRequiredDescription
idYesProvider config ID to update
kindYesProvider kind
nameYesDisplay name
base_urlNoAPI base URL
api_keyNoAPI key
enabledNoWhether the provider is active
DELETE/api/providers/config/{id}Remove Provider Config

Delete a persisted provider configuration and deregister its adapter.

GET/api/healthHealth Check

Returns daemon health status.

Response 200 OK

{"status": "ok"}

# SSE Event Stream

GET/api/events

Server-Sent Events stream for real-time task lifecycle updates.

EventDescription
task.queuedTask was added to the queue
task.processingTask is being processed by an LLM
task.completedTask completed successfully
task.failedTask processing failed
task.cancelledTask was cancelled
task.too_largeTask exceeded context window
task.no_providerNo provider available for the task

Event Format:

event: task.completed
data: {"type":"task.completed","taskId":"abc-123","status":"COMPLETED"}

Example: Submit Task via MCP

// Request
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "submit_task",
    "arguments": {
      "projectPath": "/path/to/project",
      "targetFile": "handler.go",
      "instruction": "Add error handling to the HTTP handler",
      "command": "execute"
    }
  }
}

// Response
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"id\":\"abc-123\",\"status\":\"QUEUED\"}"
      }
    ]
  }
}
