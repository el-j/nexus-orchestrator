Everything you need to
orchestrate AI at scale

From local LLMs to cloud providers, single tasks to complex pipelines — nexus-orchestrator handles the routing, memory, and orchestration so you can focus on building.

🔀

Multi-Backend Routing

Auto-discovers and routes to LM Studio, Ollama, OpenAI, Anthropic, or any OpenAI-compatible endpoint. Per-task model selection with provider hints.

🧠

Session Memory

Every project path gets its own SQLite-backed conversation history. Multi-turn context maintained automatically across tasks.

🔌

MCP Server

Built-in JSON-RPC 2.0 server on port 63988, compatible with Claude Desktop and any MCP client. Six tools ready out of the box.

🌐

Full REST API

Complete task management on port 63987 — submit, list, cancel, monitor. Real-time updates via Server-Sent Events.

🛡️

Context Guard

Pre-flight token estimation prevents prompt overflow. Tasks exceeding context limits are flagged as TOO_LARGE immediately.

⚡

Smart Discovery

Auto-detect running LLM backends with health checks and automatic failover when a provider goes down.

🎯

Command Routing

Classify tasks as "plan" or "execute". Enforces that execution tasks have a prior plan, preventing uncoordinated changes.

🖥️

Desktop GUI

Native Wails desktop app with embedded HTTP API, real-time task monitoring, system tray, and provider management.

🔌

VS Code Extension

Submit tasks, monitor the queue, and switch providers without leaving your editor. Available as a .vsix for VS Code 1.85+.

Up and running in 60 seconds

  1. 1
    Build from source or download
    CGO_ENABLED=1 go build -o nexus-daemon ./cmd/nexus-daemon/...
  2. 2
    Start the daemon
    Run ./nexus-daemon — HTTP API on :63987, MCP on :63988
  3. 3
    Connect your LLM provider
    LM Studio, Ollama, or set NEXUS_OPENAI_API_KEY for cloud
  4. 4
    Submit your first task
    Via HTTP API, MCP, CLI, or Claude Desktop
Full installation guide 
# Build
CGO_ENABLED=1 go build -o nexus-daemon ./cmd/nexus-daemon/...

# Start
./nexus-daemon
# HTTP API  → http://localhost:63987
# MCP       → http://localhost:63988/mcp
# Dashboard → http://localhost:63987/ui
curl -X POST http://localhost:63987/api/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "projectPath": "/path/to/project",
    "targetFile": "auth.go",
    "instruction": "Add JWT auth middleware",
    "command": "execute"
  }'
{
  "jsonrpc": "2.0",

  "method": "tools/call",
  "params": {
    "name": "submit_task",
    "arguments": {
      "projectPath": "/path/to/project",
      "targetFile": "auth.go",
      "instruction": "Add JWT auth middleware"
    }
  }
}

Hexagonal architecture, ports & adapters

The core business logic never imports adapter code. All external concerns — LLMs, SQLite, filesystem — are abstracted behind interfaces for maximum testability and replaceability.
