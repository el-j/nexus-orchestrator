Quick Install

Install the latest CLI + Daemon with a single command:

curl -sSfL https://raw.githubusercontent.com/el-j/nexus-orchestrator/main/scripts/install.sh | sh

Detects your OS and architecture automatically. Installs to ~/.local/bin.

🔒

Verify Your Download

Each release includes SHA256SUMS.txt with SHA-256 hashes for every archive.

🍎

macOS / Linux

# Download checksums
curl -sSfLO https://github.com/el-j/nexus-orchestrator/releases/latest/download/SHA256SUMS.txt

# Verify (macOS)
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
🐧

Linux (sha256sum)

# Download checksums
curl -sSfLO https://github.com/el-j/nexus-orchestrator/releases/latest/download/SHA256SUMS.txt

# Verify (Linux)
sha256sum -c SHA256SUMS.txt --ignore-missing
🪟

Windows (PowerShell)

# PowerShell
Get-FileHash .\nexus-orchestrator-windows-amd64.zip -Algorithm SHA256
# Compare with SHA256SUMS.txt

System Requirements

🍎

macOS

  • macOS 11 (Big Sur) or later
  • Apple Silicon or Intel processor
  • Native .app bundle included
🪟

Windows

  • Windows 10 (version 1809) or later
  • 64-bit processor (x86_64 or ARM64)
  • WebView2 runtime (usually pre-installed)
🐧

Linux

  • Ubuntu 20.04+ / Debian 11+ / Fedora 36+
  • x86_64 or ARM64 processor
  • GTK 3 and WebKit2GTK (Desktop app)
🔧

Build from Source

  • Go 1.26+ with CGO_ENABLED=1
  • C compiler (gcc / clang) for sqlite3
  • Wails v2 for Desktop builds
📦

What's Included

🖥️ Desktop App

  • Full Wails GUI with task dashboard
  • Embedded HTTP API on port 63987
  • Embedded MCP server on port 63988
  • Provider auto-discovery & health UI
  • Per-project session viewer

⚙️ Daemon (nexus-daemon)

  • Headless background service
  • HTTP API on port 63987
  • MCP server on port 63988
  • Ideal for servers & CI environments
  • Configurable via environment variables

📟 CLI (nexus-cli)

  • Thin HTTP client — no embedded LLM logic
  • Submit, list, cancel, and monitor tasks
  • Connects to daemon at 127.0.0.1:63987
  • Scriptable for automation & pipelines

🔌 VS Code Extension

  • Submit tasks directly from the editor
  • Task queue tree view sidebar
  • Status bar with live daemon health
  • Provider & model picker command
  • Connects to daemon at 127.0.0.1:63987
